# AppleGate Group Power BI Dashboard

A Power BI dashboard project for AppleGate Group analyzing ₦188.67M in transactions across 20 cities, identifying credit risk, and providing executive recommendations.

## 📁 Project Files
- `AppleGate_Dashboard.pbix` - Open in Power BI Desktop
